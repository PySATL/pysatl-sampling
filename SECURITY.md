# Security Policy

## Supported Versions

PySATL Sampling is currently in early development. Security fixes are applied to
the latest development line and to the latest published release once releases
are available.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting or create a private security
advisory for this repository. If that is not available, contact one of the
maintainers:

- Mikhail Mikhailov ([desiment](https://github.com/desiment)).
- Vladimir Kutuev ([vkutuev](https://github.com/vkutuev)).
- Leonid Elkin ([LeonidElkin](https://github.com/LeonidElkin)).

When reporting a vulnerability, include:

- A short description of the issue.
- A minimal reproduction if possible.
- Affected versions or commits.
- Any known workarounds.

We will acknowledge the report, investigate it, and coordinate disclosure once a
fix is available.
